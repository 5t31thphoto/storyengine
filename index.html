Workflow

  1. Use the Wizard to create a 46-page skeleton (all links formula-locked).
  2. Go to Pages, pick a page, write the title + body. Choice wording and dice range labels are editable; targets are locked.
  3. Orange dots = still placeholder text. Green = written. Ending colors indicate good / funny / secret.
  4. Ledger & Meta for cover/intro/footer text and the endings checklist.
  5. Validate checks links, reachability, ledger match, and formula compliance.
  6. LLM Author Prompt produces a ready-to-paste prompt so a language model can draft a full sequel JSON.
  7. Save / Open projects as plain .json files.

Secrets

Page 3 must carry the classic hidden trigger routed to page 45. Extra secrets can be added on any dice page via the italic note + target page fields; the validator inventories them.


PDF

Click Build PDF in the toolbar to generate and download a full multi-page letter-size PDF of the entire book (cover, intro, all story pages, ledger). The layout approximates the published series style.
